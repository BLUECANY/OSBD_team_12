## 1. 후보 조사 결과

| 후보 | 상태 | 비고 |
|---|---|---|
| 네이버 쇼핑 검색 API | **사용 불가** | 2026-07-31 종료, 대체 API 없음. 신규 키 발급 차단. 여러 2차 자료(개발자센터 공지 "Search API, Search Trend, Shopping Insight 서비스 종료 및 NAVER API HUB 이관 안내"를 인용)로 확인. 공식 공지 원문은 팀원이 직접 한 번 더 확인할 것 |

| **AI 웹검색 (Gemini API + Google Search 연동)** | **1순위 후보** | 무료 한도 있음 (아래 2번 참고). Flash 계열 모델 사용 |
| AI 웹검색 (Claude / OpenAI / Perplexity API) | 보조 후보 | 유료 결제 필요 |

## 2. 이용 조건 (Gemini API, 직접 확인할 것)

- 확인 페이지: https://ai.google.dev/gemini-api/docs/pricing , https://ai.google.dev/gemini-api/docs/rate-limits
- 조사 시점 자료 기준: 무료 티어는 Flash 계열 모델 위주, Google Search 연동은 월 약 5,000회까지 무료 후 유료(1,000회당 약 $14). 포럼 글 기준이라 **정책이 바뀌었을 수 있으니 위 공식 페이지에서 숫자를 다시 확인해 아래 칸에 적을 것**
- 우리 프로젝트 사용량 추정: 검증 30~50회 + 개발 테스트 수백 회 → 무료 한도 안에서 가능한지 확인
