# 국내가 검색 방식 비교 (담당: 강민지)

작성일: 2026-11-05 / 수정일: 2026-11-25

## 0. 요약 (현재 상태)

- 1차로 Gemini 웹검색을 구현했으나 링크·가격 정확도를 보장할 수 없어, **SerpApi(네이버 검색 결과) + Gemini 분류**로 방식을 변경했다.
- 3번 실험(상품 3개, 사람이 가격 일치·링크 이동을 직접 확인) 결과, SerpApi 방식을 최종 선택했다. 근거와 한계는 4번에 기록한다.

## 1. 후보 조사 결과

| 후보 | 상태 | 비고 |
|---|---|---|
| 네이버 쇼핑 검색 API | **사용 불가** | 2026-07-31 종료, 대체 API 없음. 신규 키 발급 차단. 여러 2차 자료(개발자센터 공지 "Search API, Search Trend, Shopping Insight 서비스 종료 및 NAVER API HUB 이관 안내"를 인용)로 확인. 공식 공지 원문은 팀원이 직접 한 번 더 확인할 것 |
| NAVER API HUB 검색(뉴스/블로그/웹) + 가격 추출 | 제외 | 상품 검색 API가 아니라 글에서 정규식으로 가격을 뽑는 우회 방식. 실험: 블로그 검색 20건 중 8건에만 가격 포함(가장 높은 값), 뽑힌 가격의 정확도는 검증하지 못함 |
| 쿠팡 파트너스 검색 API | 제외 | 최종 승인에 누적 판매 조건이 있어 현실적으로 사용 불가. 한 개발 사례에서 시간당 호출 10회 제한과 약관상 용도(제휴 링크 목적) 문제를 보고함 (2차 자료, 직접 확인 필요) |
| 쿠팡 개발자센터 / 스마트스토어 커머스 API / 11번가 Open API | 제외 | 확인한 문서가 판매자 전용(자기 상품 등록·관리용)이라 상품 검색 불가 |
| AI 웹검색 (Gemini API + Google Search 연동) | 시도 후 보류 | 아래 2번, 3번 참고. 링크·가격을 AI가 글로 다시 쓰기 때문에 정확도를 보장할 수 없음 |
| AI 웹검색 (Claude / OpenAI / Perplexity API) | 제외 | 유료 결제 필요, 같은 구조적 한계 |
| **SerpApi (engine=naver)** | **채택(확정)** | 네이버 검색 결과의 쇼핑 영역을 구조화된 데이터로 반환. 가격은 숫자, 링크는 API 값 그대로 사용. 무료 월 250회 |

※ 이전 조사에서는 SerpApi를 "유료 크롤링 서비스"로 보고 제외했으나, 무료 플랜(월 250회)이 있고 네이버 엔진을 제공하는 것을 확인해 다시 후보에 넣었다.

## 2. 이용 조건

### 2-1. Gemini API (Google Search 연동)

| 항목 | 확인한 값 | 출처 / 확인 수준 |
|---|---|---|
| 무료 키로 검색 연동 사용 | **불가** (429 RESOURCE_EXHAUSTED) | 직접 실행으로 확인 |
| 해결 방법 | 결제 수단 등록 + 선불 충전(최소 8,000원), 유료 프로젝트에서 사용 | 직접 결제하여 확인. 가입 시 $300 크레딧은 Gemini에 사용 불가 |
| 검색 연동 무료 한도 | 유료 프로젝트 기준 월 약 5,000회, 이후 1,000회당 약 $14 | 포럼 글 기준, 공식 페이지 재확인 필요 |
| 사용 가능 모델 | 검색 연동 지원 모델만 사용 가능(예: gemini-3.5-flash-lite, gemini-3.8-flash). 구형 모델은 종료 예정 | Firebase 문서 기준 |
| 분당 호출 제한 | 미확인 | 공식 rate-limits 페이지 확인 필요 |
| API 키 발급 방법 | Google AI Studio 로그인 → Get API key | |

확인 페이지: https://ai.google.dev/gemini-api/docs/pricing , https://ai.google.dev/gemini-api/docs/rate-limits

### 2-2. SerpApi

| 항목 | 확인한 값 | 출처 |
|---|---|---|
| 무료 플랜 | 월 250회, 시간당 50회 | https://serpapi.com/pricing |
| 유료 플랜 | Starter $25/월 1,000회부터 | 위와 같음 |
| 네이버 엔진 응답 | shopping_results: title, link, price(숫자), stores, thumbnail | https://serpapi.com/naver-search-api |
| 링크 형태 | 판매처 직접 링크가 아니라 네이버 쇼핑 중계 링크(cr3.shopping.naver.com/bridge/searchGate...) 또는 광고 링크(adcr.naver.com...) | 위와 같음 |
| API 키 발급 방법 | serpapi.com 가입 → 대시보드에서 API key 확인 | |

- 프로젝트 사용량 추정: 검증 30~50회 + 개발 테스트 수백 회. 팀원 4명이 각자 테스트하면 월 250회가 빠르게 소진될 수 있어, 코드에 캐시(1시간)와 월 호출 한도(기본 200회)를 넣음.

## 3. 실험: 같은 상품으로 비교

상품 선택 기준 (A와 같은 상품 사용 권장)
1. 모델명이 확실한 상품
2. 브랜드만 알고 모델명이 애매한 상품
3. 외국어 상품명 (일본어 등)

### 3-1. 상품 1: 로지텍 MX Master 3S (모델명 확실)

| 방식 | 실행 | 반환 건수 | 반환 가격대 | 소요 시간(초) | 비고 |
|---|---|---|---|---|---|
| Gemini 웹검색 | 1회차 | 5 | 99,710~139,000원 | 3.2 | 링크는 완전한 URL(네이버 광고 중계 링크). 해외구매 상품(99,710원)이 정품으로 섞임 |
| Gemini 웹검색 | 2회차 | 3 | 102,390~125,390원 | 3.4 | 항목 1의 판매처(11번가)와 링크(다나와)가 서로 다름 |
| Gemini 웹검색 | 3회차 | 3 | 103,950~125,390원 | 2.5 | 링크가 `x=...`로 잘려 사용 불가 |
| SerpApi(네이버) | 1회차 | 5 | 미기록 | 4.5 | 링크·가격은 API 값 그대로. 가격 일치 5/5, 링크 이동 5/5 (사람이 확인) |

관찰: 같은 검색어인데 Gemini는 건수(5/3/3), 판매처, 가격, 링크가 실행마다 달랐고 일부 링크는 지어낸 값이었다.

### 3-2. 상품 2: 캔메이크 파우더 (브랜드만 알고 모델명 애매)

검색어: `캔메이크 파우더` / SerpApi(네이버) / 반환 5건 / 4.2초 (2026-11-25, 사람이 직접 확인)

| # | 반환된 상품(요약) | 반환 가격 | 실제 가격·수량 | 가격 일치 | 링크 이동 | 판매처 | 분류 |
|---|---|---|---|---|---|---|---|
| 1 | 마시멜로 피니쉬 팩트파우더 MO 10g, 2개 | 33,500원 | 동일 | O | O | 쿠팡 | same |
| 2 | 마시멜로 피니시 파우더 10g MI, 1개 | 25,300원 | 동일 | O | O | 쿠팡 | same |
| 3 | 마쉬멜로우 피니쉬 팩트파우더 MO 10g, 3개 | 51,500원 | 동일 | O | O | 쿠팡 | same |
| 4 | 마시멜로우 피니쉬 미니 파우더 5g, 4종 중 택1 | 12,050원 | 동일 | O | O | 캔메이크 공식스토어 | same |
| 5 | 마시멜로우 피니쉬 팩트파우더 매트오클 10g | 16,990원 | 동일 | O | O | 네이버 쇼핑 | same |

집계: 가격 일치 5/5건, 링크 이동 5/5건

관찰
- 링크 5건 모두 정상 이동했다. 3건은 네이버 광고 중계 링크(ader.naver.com), 2건은 네이버 쇼핑 중계 링크(cr3.shopping.naver.com)였다.
- 가격과 수량이 표시된 값과 이동한 페이지의 값이 모두 같았다. 가격은 시간에 따라 바뀔 수 있다.
- **5건 모두 `same`으로 분류**됐다. 2개/3개 묶음과 5g 미니 상품도 동일 상품으로 분류되어, 그대로 가격을 비교하면 개당 가격 차이가 반영되지 않는다. 대체상품(alternative)은 0건이었다.
- 판매처는 쿠팡 3건, 공식스토어 1건, 네이버 쇼핑 1건으로 다양성이 낮았다.

### 3-3. 상품 3: 매지컬 치이카와 (외국어 캐릭터 상품명)

검색어: `매지컬 치이카와` / SerpApi(네이버) / 반환 5건 / 2.1초 (2026-11-25, 사람이 직접 확인)

| # | 반환된 상품(요약) | 반환 가격 | 가격 일치 | 링크 이동 | 판매처 | 분류 |
|---|---|---|---|---|---|---|
| 1 | 먼작귀 다크 모몽가 매지컬 차지 인형 키링 | 59,600원 | O | O | 오모재팬 | same |
| 2 | [2SET] 먼작귀 오데 고블린 키링 인형 | 88,400원 | O | O | 오모재팬 | same |
| 3 | 치이카와 키링 매지컬 우사기 하치와레 | 35,000원 | O | O | 티디티 스토어 | same |
| 4 | 나가노 치이카와 매지컬 2탄 인형 키링 | 38,900원 | O | O | 나린나리 | same |
| 5 | 나가노 모몽가 블랙 마법 소녀 키링 | 44,900원 | O | O | 나린나리 | alternative |

집계: 가격 일치 5/5건, 링크 이동 5/5건

관찰
- 인형이 아니라 키링·파우치류가 대부분이었고, 가격이 35,000~88,400원으로 넓게 퍼졌다.
- 검색어에 `하치와레`를 덧붙이자(`하치와레 매지컬 치이카와`) 5건 중 4건이 다른 상품으로 바뀌었다. 검색어 변화에 민감하다.
- 같은 상품(오모재팬 [2SET] 88,400원)이 검색어에 따라 same/alternative로 다르게 분류됐다.
- [2SET](2개 묶음) 상품이 same으로 분류되어 단품과 가격 비교가 왜곡될 수 있다.
- SerpApi는 같은 검색어를 1시간 안에 다시 호출하면 캐시된 결과를 돌려준다(공식 문서). 따라서 1시간 안의 반복 실행에서 결과가 같았다는 것은 안정성의 근거로 쓸 수 없다.

## 4. 선택과 근거

- 선택한 방식: **SerpApi(engine=naver)로 상품 검색 + Gemini로 동일/대체 분류**. Gemini 분류 실패 시 RapidFuzz 유사도로 보완.
- 근거:
  - 가격과 링크를 AI가 다시 쓰지 않고 API 값 그대로 사용하므로, 링크가 잘리거나 지어지는 문제가 구조적으로 없다.
  - 같은 검색어의 결과가 Gemini 방식보다 안정적일 것으로 예상(반복 실행으로 확인 필요).
  - 로지텍 MX Master 3S, 캔메이크 파우더, 매지컬 치이카와 실험에서 가격 일치 각 5/5건, 링크 이동 각 5/5건(합계 15/15건)을 확인했다. (Gemini 방식은 링크가 잘리거나 판매처와 링크가 어긋난 사례가 있었다.)
  - 무료 플랜(월 250회)으로 개발·검증이 가능하고, Gemini는 분류 호출만 하므로 비용이 작다.
- 한계와 대응:
  - 링크는 판매처 상품 페이지가 아니라 네이버 쇼핑 중계 링크이다. 화면에 "네이버 쇼핑에서 확인" 안내를 둔다.
  - 판매처(stores) 값이 "판매처 64"나 광고 문구로 올 수 있어 코드에서 정리한다.
  - 묶음(2개, 3개)과 용량 차이(5g 미니)가 모두 `same`으로 분류되어 가격 비교가 왜곡될 수 있다. 수량·용량을 구분하도록 분류 규칙을 개선해야 한다.
  - 검색어에 단어를 덧붙이면 결과 상품과 분류가 크게 달라지고, 같은 상품이 검색어에 따라 same/alternative로 다르게 분류되어 일관성이 낮다.
  - 광고 링크(ader.naver.com)가 섞여 나온다. 이동은 정상이었으나 화면에서 광고 여부를 표시하는 것이 좋다.
  - 네이버 화면 구조가 바뀌면 SerpApi가 대응하기 전까지 결과가 달라질 수 있다.
  - 무료 월 250회 제한: 캐시와 월 호출 한도로 보호한다.
  - 가격은 "AI/검색 결과 참고용"이며 실제 가격은 링크에서 확인하도록 안내한다.
- 최종 확정: 상품 3개 실험 결과를 반영하여 SerpApi(네이버) + Gemini 분류로 확정한다. 단, 묶음·용량 구분과 분류 일관성은 개선 과제로 남긴다.
