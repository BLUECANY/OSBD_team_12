# 10주차 팀 데이터 인터페이스 정의서

우리 프로젝트의 각 모듈(OCR -> 가격 변환 -> 검색 -> 판단) 간에 주고받을 데이터 형식을 다음과 같이 확정합니다.

---

## 1. A파트 (OCR) ➡️ B파트 (가격 변환) 및 전체 공통
- **역할**: 이미지에서 텍스트를 추출하여 상품명과 브랜드, 현지 가격 정보를 넘겨줍니다.
- **데이터 형식**: Python `dict` (딕셔너리)
- **Key 명세**:
  - `brand` (str): 인식된 브랜드명 (예: "Sony")
  - `product_name` (str): 인식된 상품 모델명 (예: "WH-1000XM5")
  - `local_price` (int): 영수증 또는 라벨에서 인식된 현지 가격 숫자 (예: 39800)

---

## 2. B파트 (가격 변환) ➡️ 공통 및 화면 표시
- **역할**: 선택된 현지 통화와 A파트가 준 가격을 바탕으로 원화(KRW)로 환산합니다.
- **데이터 형식**: Python `int` (정수형 변수)
- **출력 데이터**: `krw_price` (예: 360000)

---

## 3. C파트 (국내 온라인 검색) ➡️ 공통 및 화면 표시
- **역할**: A파트가 찾아낸 상품명(`product_name`)을 바탕으로 국내 쇼핑몰 최저가들을 검색해 리스트로 반환합니다.
- **데이터 형식**: Python `list` 안에 `dict`가 들어간 형태 (`list of dict`)
- **Key 명세**:
  - `mall` (str): 쇼핑몰 이름 (예: "쿠팡", "네이버")
  - `price` (int): 해당 쇼핑몰의 판매 가격 (예: 420000)
  - `link` (str): 해당 상품 상세 페이지 URL (예: "https://...")

---

## 4. 4인 공통 (구매 여부 판단 및 최종 추천)
- **역할**: B파트의 `krw_price`와 C파트의 최저가 데이터를 비교하여 최종 추천 문구와 효과를 화면에 출력합니다.
